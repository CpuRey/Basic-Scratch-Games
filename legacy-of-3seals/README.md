# Legacy Of 3 Seals
Note: Click the green flag to play again.

* Place the right words into the missing gaps of the poem.
* Your time is running out. Starting from 30s. For every correct guess: +5s, if not then -3s.
* Fail to complete the poem will result in Failure.
